VéloCité — Campagne de test complète

Contexte : une borne de location de vélos livrée en 5 versions pendant ma formation, avec une spécification à analyser.
Ce que j'ai fait : j'ai relu la spécification, écrit le plan de test, conçu 28 cas de test avec les techniques ISTQB (valeurs limites, tables de décision, transitions d'état), exécuté 5 campagnes et rédigé les fiches d'anomalie et le rapport de fin de tests.
Résultat : 14 anomalies trouvées et suivies jusqu'à leur correction, cahier de tests prêt à importer dans Jira / Xray.
Outils : Jira, Xray, Confluence, Excel

Médiathèque — Tests d'API

Contexte : une application de prêt de livres avec une API REST et une base de données.
Ce que j'ai fait : j'ai testé l'API à la main avec Postman, automatisé les mêmes vérifications avec Robot Framework, et contrôlé directement en base, avec des requêtes SQL, que chaque emprunt et chaque retour étaient bien enregistrés.
Résultat : 31 tests automatisés, lancés sur GitHub à chaque mise à jour.

Automatisation des tests d'interface web

Contexte : trois applications web : un générateur de mot de passe, la Médiathèque et la borne VéloCité.
Ce que j'ai fait : j'ai commencé avec Selenium IDE, relu et corrigé les scripts proposés, puis réécrit les tests dans Robot Framework avec Selenium et Playwright, en séparant les écrans (Page Object) des scénarios.
Résultat : 50 tests automatisés, dont la régression de VéloCité, lancés sur GitHub à chaque mise à jour ; 5 anomalies documentées sur le générateur.
Outils : Selenium IDE, Selenium, Playwright, Robot Framework, GitHub

Accessibilité et compatibilité

Contexte : un audit de la Médiathèque et du générateur de mot de passe selon le RGAA, et des essais sur différentes tailles d'écran.
Ce que j'ai fait : j'ai lancé une analyse automatique (axe), vérifié 15 critères RGAA à la main, testé chaque parcours au clavier seul, puis sur mobile, tablette, grand écran et au zoom 200 %.
Résultat : 12 anomalies, dont un indicateur de sécurité invisible pour les lecteurs d'écran, que l'outil automatique n'avait pas vu.
Outils : axe DevTools, RGAA 4.1, WCAG 2.1, Jira
